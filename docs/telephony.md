# מרכזייה וצינתוקים (טכנוליין)

## משתני סביבה (בשרת האירוח, לא בקוד)
| משתנה | מה זה |
|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | המפתח הסודי של Supabase (Settings → API Keys → secret). שרת בלבד. |
| `PBX_SECRET` | מחרוזת אקראית ארוכה. היא חלק מכתובות המרכזייה. |
| `TZINTUK_SECRET` | מחרוזת אקראית לעובד הצינתוקים. |
| `TZINTUK_CID` | (לא חובה) קוד 4 ספרות שמוצג בזיהוי הצינתוק. ברירת מחדל 1010. |
| `TECHNOLINE_CALLER_ID` | (לא חובה) מספר יוצא מאושר אצל טכנוליין. |

## מה להזין בטכנוליין (Module API)
- קו בעלי דירות: `https://<הדומיין>/api/pbx/owner/<PBX_SECRET>`
- קו לקוחות ראשי: `https://<הדומיין>/api/pbx/main/<PBX_SECRET>`

## צינתוק
הצינתוק הוא שיחה קצרה בלי קול (בקשת `makeCall`) שמראה קוד בזיהוי המתקשר. בעל הדירה מתקשר חזרה לקו שלו והמערכת מקריאה מה נתפס.
- `makeCall` עובד רק מכתובת IP קבועה שאושרה בטכנוליין, ולכן העובד חייב לרוץ על שרת עם IP קבוע.
- הפעלה: cron בשרת פעם בדקה: `curl -s https://<הדומיין>/api/tzintuk/<TZINTUK_SECRET>`
- עד 3 ניסיונות, בהפרש של 10 דקות, ולבעלי דירות בלי יומן מסונכרן בלבד.

## מה צריך לוודא מול טכנוליין
1. תור המתנה עם הקראת "הנך מספר X": האם נתמך דרך `queueRouting`, ומה ה-`routerId`.
2. הקלטת שיחות: האם אפשר להפעיל על הקו, ואיפה מורדות ההקלטות (כדי לקשר לכרטיס הלקוח).
3. מוזיקת רקע בפתיחה ובהמתנה: האם `setMusic` מנגן מוזיקה בתפריט, או שצריך קובץ שמע.
4. אישור כתובת ה-IP הקבועה של השרת ל-`makeCall`.

## בעלי דירות
כל בעל דירה צריך בעריכה: טלפון (לזיהוי), טלפון לצינתוק, קוד PIN. לכל דירה: מספר דירה קצר (למרכזייה).
